# Análise de Vendas de um E-commerce Brasileiro

Projeto de análise de dados desenvolvido para estudar e aplicar conceitos de Data Analytics utilizando Python, SQL e Power BI.

## Objetivo

Analisar dados de vendas de um e-commerce brasileiro e identificar padrões, tendências e oportunidades de negócio.

## Tecnologias

- Python
- Pandas
- SQL
- Power BI
- Git
- GitHub
